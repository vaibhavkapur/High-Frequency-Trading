# Integration Results Index

This directory stores reproducible raw benchmark artifacts, environment provenance, and markdown summaries generated by `scripts/run_benchmarks.sh`.

## Recorded Runs

| Directory | Host | Compiler / Build | Highlights |
|---|---|---|---|
| [`apple_m5_release/`](apple_m5_release/) | Apple M5 (`arm64`, 10 cores), macOS 26.5.1 | AppleClang 21.0.0 (`Release`, `-O3 -DNDEBUG`) | 8 stage benchmarks + 3 E2E comparative studies (`PoolBook` vs `MapBook`, Direct vs SPSC, Clean vs 15%-loss MDF1) + separate `tick_to_decision`, `order_submit_to_ack`, `order_submit_to_fill` distributions. See [`apple_m5_release/summary.md`](apple_m5_release/summary.md). |

## Files Per Run

- `environment.json` — CPU, architecture, OS, compiler flags, clock overhead provenance.
- `summary.csv` — Aggregated p50/p90/p95/p99/p99.9, throughput, IPC, RepCV% across repetitions.
- `raw_samples.csv` — Raw per-sample wall-clock measurements across all repetitions.
- `e2e_latency.json` — Separate `tick_to_decision`, `order_submit_to_ack`, and `order_submit_to_fill` percentiles + checksum equivalence flags.
- `git_sha.txt` — Exact Git commit SHA.
- `summary.md` — Auto-generated markdown report from `scripts/summarize_benchmarks.py`.
