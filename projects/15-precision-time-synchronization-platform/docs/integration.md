# Integration Boundaries and Dependencies

## 1. Adapter Boundaries within `Trading-High-Frequency`

`precision-time-synchronization-platform` is self-contained and has **no compile-time or runtime coupling** to neighboring projects, while maintaining clean adapter compatibility with verified sibling projects in this repository:

| Neighboring Project (verified path) | Reusable Interface / Concept | Integration Boundary |
|---|---|---|
| `projects/12-kernel-bypass-networking-lab/include/kbnl/clock.hpp` & `transport.hpp` | Local receive/send timestamp capture on UDP/AF_XDP packets | Wrap packet capture timestamps into `ptsp::ProvenancedTimestamp` with explicit `ClockDomain::MonotonicRaw` or `ClockDomain::Tai` (if NIC HW PTP is active) and `TimestampRole::ReceiveTime`, then pass into `ptsp::FailClosedOrderer::ingest()`. |
| `projects/17-market-microstructure-analytics-engine/` | Causal L2/L3 event replay engine | Consume `ptsp::OrderedEvent` emitted by `FailClosedOrderer` as a pre-validated, domain-checked causal event stream; halt downstream analytics whenever `OrderingState::HaltedFailClosed` is observed. |

No implementation files are copied across projects; integration is strictly via the typed C++ headers (`include/ptsp/*.hpp`) or versioned JSON/CSV/JSONL artifacts (`ptsp.v1`).

## 2. Optional `linuxptp` / Linux Kernel Integration

- **Compile-time optional**: Controlled by CMake option `PTSP_ENABLE_LINUX_PTP` (default `ON` on Linux, safely inactive on macOS/Darwin).
- **Runtime capability check**: `LinuxPtpHardwareAdapter` checks `<linux/net_tstamp.h>`, `/dev/ptp*`, and `ETHTOOL_GET_TS_INFO` (`SOF_TIMESTAMPING_TX_HARDWARE | SOF_TIMESTAMPING_RX_HARDWARE | SOF_TIMESTAMPING_RAW_HARDWARE`).
- **Optional external daemon (`linuxptp`: `ptp4l` / `phc2sys` / `pmc`)**: Not bundled and not required to build or validate `ptsp`. On a Linux host with a PTP-capable NIC, `ptp4l` disciplines the NIC PHC (`/dev/ptp0`) to the grandmaster in `TAI`; `LinuxPtpHardwareAdapter` reads that PHC directly without claiming hardware accuracy when `/dev/ptp*` or NIC support is absent.
- **Production boundaries**: Live trading gateways, production exchange multicast feeds, customer data, and credentials are strictly excluded from this research prototype.
