# Generated Results

This directory holds reproducible benchmark and simulation outputs produced directly from the scripts in `scripts/`:

- `benchmarks/`: Generated by `./scripts/run_benchmarks.sh` (`environment.json`, `router_latency.json`, `router_latency.txt`).
- `experiments/`: Generated by `python3 scripts/run_experiments.py` (`scenarios.json`, `scenarios.csv`, `sensitivity.json`, `summary.md`).

All published measurements in `README.md` and `docs/` are taken directly from these raw files — never fabricated.
